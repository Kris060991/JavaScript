Задание 1. Создание функций, имитирующих запросы
Что нужно сделать
- С помощью setTimeout создайте две функции, каждая из которых будет возвращать промис с массивом URL изображений. Возвращённые промисы должны завершаться за случайное время от двух до пяти секунд.
- Вызовите эти функции при загрузке страницы, обработайте возвращённые промисы и выведите изображения на страницу.

Задание 2. Создание progress bar
Что нужно сделать
- Создайте элемент div с id=”progress-bar”, высотой 20 px и максимальной шириной 500 px. Стилизуйте его на своё усмотрение — главное, чтобы элемент был виден на странице.
- Создайте функцию progress(time) (time — количество секунд), которая анимирует блок progress bar так, чтобы сначала он имел ширину 0 pх, а затем за заданное время растягивался на максимальную ширину (советуем использовать transform: scaleX()). Минимальное время, за которое растягивается блок, — две секунды. Анимация должна быть плавной.

Задание 3. Обработка результата
Что нужно сделать
Объедините предыдущие задачи в одно решение.
- Выполните одну из мок-функций. После вычисления времени в мок-функции создайте и выведите для неё progress bar с заданным временем.
- По истечении времени выведите результат и вызовите вторую функцию. Аналогично первой создайте и выведите для неё progress bar.
- Для удобства и переиспользования функции progress можете добавить в неё аргументы блоков, которые вы собираетесь использовать.
