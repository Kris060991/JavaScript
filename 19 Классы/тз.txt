Задание 1
Создайте небольшое веб-приложение для отображения списка доставок, которым мог бы пользоваться курьер в своей работе. Для создания карточки доставки создайте класс Delivery, конструктор которого принимает три аргумента: имя покупателя, адрес и расстояние. Инициализация должна выглядеть следующим образом:

Пример инициализации: 

new Delivery("Ольга", "ул. Вымыслов, д. 12", 8);
Так как это список доставок, то для хранения экземпляров классов нужно использовать массив, который удобно обрабатывать циклом.

Пример массива:

const deliveryArr = [
  new Delivery("Ольга", "ул. Вымыслов, д. 12", 8),
  new Delivery("Дмитрий", "ул. Задачная, д. 7", 3),
  new Delivery("Оля", "ул. Ткачей, д. 43", 11)
];

Класс должен иметь методы создания элементов и возможность управления видом карточки с помощью сеттеров и геттеров за пределами самого класса. Для объявления класса создайте отдельный модуль.

Задание 2
Доработайте мини-приложение списка доставок из задания 1: создайте для каждой карточки кнопку для изменения (редактирования) доставки и дополнительный атрибут со статусом доставки, влияющий на внешний вид карточки. Всего у доставки должно быть три статуса:

delivery — доставляется;
delivered — доставлен;
canceled — отменён.

Пример инициализации: 

new EditDelivery("Дмитрий", "ул. Задачная, д. 7", 3, "delivered");
При клике на кнопку «Изменить» должно отобразиться окно редактирования доставки с полями:

имя — текстовое поле;
адрес — текстовое поле;
расстояние — текстовое поле;
статус — выпадающий список.

Новые возможности (редактирование и добавление статуса) должны быть выполнены в унаследованном классе. Для статуса доставки предусмотрите возможность изменения за пределами класса.

Задание 3
Доработайте мини-приложение списка доставки и добавьте в класс EditDelivery статический метод расчёта суммарного расстояния всех доставок. У метода должен быть единственный атрибут, являющийся массивом классов доставок.

Пример вызова метода для расчёта общего расстояния:

сonst totalDistance = EditDelivery.getTotalDistance(deliveryArr)

Важно то, что доставки со статусом canceled (отменена) суммироваться не должны.

Добавьте в приложении кнопку, при клике на которую будет вызван метод расчёта общего расстояния, и покажите итоговый результат на экране
